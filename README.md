# Simulação de Braço Robótico 4DOF com ROS 2 e Gazebo

## Objetivo
Criar um braço robótico simulado (manipulador 4DOF) com sensores virtuais simples (IMU e câmera RGB) que publica dados via ROS 2, e processar esses dados de forma básica.

## Tecnologias
- ROS 2
- Gazebo
- C++/Python (nós de processamento)
- Git para controle de versão

## Estrutura inicial
- `src/` — código-fonte dos nós e scripts
- `config/` — arquivos de configuração (URDF, parâmetros)
- `docs/` — documentação do projeto
